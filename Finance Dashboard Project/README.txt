# 📊 Interactive Finance Dashboard using Power BI

## 🚀 Project Overview
This project is an Interactive Finance Dashboard developed using Power BI. The dashboard helps analyze financial performance through dynamic visualizations, KPIs, and interactive filters.

## 🎯 Objectives
- Track revenue and profit trends
- Analyze sales performance
- Monitor financial KPIs
- Enable data-driven decision making
- Provide interactive reports and visualizations

## 🛠️ Tools & Technologies
- Power BI Desktop
- Microsoft Excel / CSV
- DAX (Data Analysis Expressions)
- Data Modeling
- Power Query

## 📈 Features
- Revenue Analysis
- Profit Analysis
- KPI Cards
- Monthly & Yearly Trends
- Interactive Slicers
- Region-wise Performance
- Product-wise Analysis
- Dynamic Visualizations
